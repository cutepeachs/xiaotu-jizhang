# 小兔记账

一个本地运行的中文记账工作台，采用奶油白、浅粉和淡黄色的兔兔风格，适配 Mac、手机和平板。无需安装依赖或构建步骤，打开 `index.html` 即可使用。

## 工作台页面

- **首页概览：** 本月收入、支出、剩余、预算进度、最近账单、支出分类和总资产。
- **每日账单：** 按日期查看收入与支出，支持搜索、筛选和修改删除；默认显示 20 笔，可按需继续加载。
- **存钱目标：** 新增多个旅行基金、心愿购物基金、应急储蓄等目标，追踪进度；默认展示 3 个，可展开全部。
- **消费分析：** 查看本月收支、结余率和较上月变化；分类拆解包含金额、占比、笔数与单笔均额，并可切换每日趋势和大额账单，避免所有分析内容堆成长页。
- **账户与资产：** 分为「资产概览」和「账户明细」两个页签；管理微信、银行卡、支付宝、现金及自定义类型，可查看资产构成、月度快照、单账户流水并进行对账。
- **账户流水：** 账户初始余额、日常收入支出和账户间转账分开记录；转账只调整账户余额，不算作收入或支出。
- **储蓄进度：** 每个目标可单独记下存入与取出金额，并保留最近的进度明细。
- **快速记账：** 常用分类快捷选择，并记住最近使用的分类和账户。
- **外观个性化：** 点击侧栏或手机顶部的兔兔图标，可改账本名称、选择四套配色、更换图标或上传背景图；图片会压缩后保存在本机。
- **预算计划：** 分为月度总预算和分类预算；按月设置总额，也可为餐饮、交通等分类单独设上限，达到 80% 时提醒，超出时标红。

## 本地数据

记录、预算、目标、账户、转账和资产快照保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。可使用侧栏底部或手机顶部「备份」按钮保存 JSON 文件。备份包含个人财务信息，请只保存在自己的设备或私人云盘中，不要公开分享；建议每月记账后备份。恢复前会提示将替换当前设备上的数据。账户月度资产采用手动快照：月底更新账户余额后，进入“账户与资产”并点击“记录本月资产”；有连续月份快照时会显示月度增减。

账户规则：添加账户时输入的是初始余额；后续关联该账户的收入增加余额、支出减少余额，账户转账从转出账户扣除并加到转入账户，不计为收入或支出。记账时选择账户，账目变更会立即反映到账户余额和总资产；未关联账户的账目只参与收支统计，不影响账户资产，并会在保存前提示。对账时输入账户实际余额，差额会作为一条有日期且可写明原因的余额校准记录，旧流水保留；如误记，可在账户流水中撤销调整。停用账户会保留余额和历史流水，但不再出现在新记账和新目标的账户选项中；已有记录仍可查看。删除有关联流水、对账记录或储蓄目标的账户会被阻止。账单搜索支持分类、备注、日期、账户名称和金额。

储蓄目标可以标记资金所在账户，但目标进度只用于用途规划，不会自动移动账户余额，也不会重复加到账户总资产。月度资产图来自手动保存的快照，不会回算历史余额；支持补录过去月份，并可编辑或删除；补录历史月份时不会再默认填入当前余额。首次记录只有一个点，连续月份保存后才有月度增减对比。资产构成比例按正余额账户合计计算，负余额单独标记。

## 发布到 GitHub Pages

这是一个纯静态网页项目，无需安装依赖或构建。将 `index.html`、`styles.css`、`app.js` 和本说明文件上传到 GitHub 仓库根目录，然后在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/(root)` 并保存。部署完成后，GitHub 会提供一个 `https://用户名.github.io/仓库名/` 网址；首次发布通常需要等待几分钟。

GitHub Pages 发布的是网页代码，记账记录、账户余额、预算和自定义外观仍保存在打开网页的那台设备浏览器中，不会自动上传到 GitHub，也不会在手机与电脑间同步。公开仓库中的网页代码任何人都能查看，因此不要把私人账单或真实账户信息写进代码。手机首次打开发布网址后，可以将网页添加到主屏幕，之后无需电脑开机即可使用。
